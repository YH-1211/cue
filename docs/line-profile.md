# Que 公式LINE プロフィール設定

LINE Official Account Manager で設定する内容のまとめ。
（コード側の応答メッセージは `app/api/line/webhook/route.ts` に実装済み・全てQue化済み）

## 画像
- **プロフィール画像**：`public/icon-512.png`（Que アイコン・案A）
- **背景 / カバー画像**：`public/line-cover.png`（1080×878px）

## ① アカウント名（20文字以内）
```
Que｜東京・関東のイベント発見
```
※シンプルにするなら `Que` のみでもOK

## ② ステータスメッセージ（20文字以内）
```
行きたいが、見つかる。
```

## ③ 説明文 / プロフィール紹介（500文字以内）
```
Que（キュー）は、東京・関東のイベントが見つかるアプリです。

アート・音楽・舞台・祭り・花火・グルメ・映画・スポーツまで、
「今週末どこ行こう？」に答えるイベントをまとめてチェックできます。

このLINEでできること
🔍「イベント」と送ると、近々の開催をご案内
📅「今日」「今週末」で日程を絞り込み
🎪「祭り」「ライブ」「アート」などジャンルで検索
📍 位置情報を送ると、近くのエリアで検索

アプリと連携すると、あなたの興味・エリアに合わせた
おすすめイベントやチケット発売のお知らせも届きます。

まずは「イベント」と送ってみてください！
```

## ④ あいさつメッセージ
コード側（Webhookの `WELCOME`）で自動送信するため、LINE Manager側は空 or 最小限でOK。
手動設定する場合の文面：
```
Que の友だち追加ありがとうございます！🎉
東京・関東のイベントが見つかるアプリ「Que」です。

このトークでできること👇
・「イベント」→ 近々の開催をお届け
・「使い方」→ アプリの説明

さらに、興味・エリアに合わせた通知を受け取るには
アプリの「通知設定」で連携コードを発行して、ここに送ってください！
```

## ⑤ 基本設定
| 項目 | 設定値 |
|---|---|
| カテゴリ | エンターテインメント または 地域・観光 |
| プロフィール画像 | icon-512.png（案A） |
| カバー画像 | line-cover.png |
